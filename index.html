Features

Everything a notes app should be

Text, checklists and freehand drawing in one place — with the organisation, reminders and security you expect, and none of the cloud.

Text notes

Titles and rich bodies, with per-note colours and pinning to keep the important things on top.

Freehand drawing

Sketch with pen, marker, highlighter, selection and eraser tools — undo, redo, and blank, ruled, grid or dotted canvases.

  • Pen
  • Marker
  • Highlighter
  • Selection
  • Eraser

Inline checklists

Turn any note into a checklist with per-item completion, and tick items off without even opening the app.

Labels & colours

Add, rename and apply labels, colour-code notes, and filter the list by label or colour in a tap.

Instant search

Search titles, body text and tags with colourful match highlighting — fast, offline and always local.

Archive & Trash

Set notes aside in the Archive, or move them to Trash where they can be restored or deleted — and auto-clear after 30 days.

Reminders

Schedule a per-note reminder and get a local notification at the right time — scheduled and delivered entirely on-device.

App lock

An optional lock using biometrics or your device credential. The app never sees your fingerprint, PIN or password.

Home-screen widget

Pin a checklist to your home screen and tick items off without opening the app.

Privacy

Your notes never leave your phone

Elite Memo Pro is built so that it cannot send your data anywhere. The app does not request the INTERNET permission, so Android itself prevents it from opening a network socket.

  • No account, no sign-in, no server component.
  • No analytics, advertising, tracking or crash-reporting SDKs.
  • Notes and labels stored in an on-device Room database.
  • Optional encrypted-at-rest protection via your device.

To post a reminder you scheduled.

No camera, microphone, location, contacts or phone permissions.

Installation

Download the signed APK from the latest release and open it on your device. Elite Memo Pro runs on Android 7.0 (API 24) and newer, and the universal build works on every architecture.

# Grab the universal APK for the newest release
curl -LO https://github.com/deepanjanxyz/notepad/releases/latest/download/EliteMemoPro-v1.0.24-24-universal.apk

# Install it over ADB (or just tap the file on the device)
adb install EliteMemoPro-v1.0.24-24-universal.apk

Because the APK is installed outside an app store, Android will ask you to allow installs from your browser or file manager the first time.

Reproducible builds

Elite Memo Pro publishes the exact APK the developer signed. F-Droid rebuilds the same commit from source; if the two match byte-for-byte, the developer's own signed APK is shipped, so your signature and update path never change.

  • Binaries points at the GitHub release asset.
  • AllowedAPKSigningKeys pins the signing certificate (SHA-256).
  • Every release is tagged and the full commit hash is recorded.

Architecture

Written in Kotlin with Jetpack Compose, split into focused Gradle modules so the domain layer stays free of Android dependencies.

:appCompose UI, navigation, app lock
:domainUse cases and models
:dataRoom database and DataStore
:coreShared utilities
:featuresFeature screens

Reminders are scheduled with WorkManager; notes, labels and settings live in an on-device Room database and Preferences DataStore.

Build from source

You need JDK 21 and the Android SDK (platform 37). The project builds with the Gradle wrapper.

git clone https://github.com/deepanjanxyz/notepad.git
cd notepad

# Debug build
./gradlew assembleDebug

# Release build (needs your own signing config)
./gradlew assembleRelease

FAQ

Questions, answered

Is it really free?

Yes. Elite Memo Pro is free and open source under the MIT License. There are no ads, no in-app purchases and no premium tier.

Does it send my notes anywhere?

No. The app does not request the INTERNET permission, so Android blocks it from opening a network connection. There is no account, no server and no sync service.

Which Android versions are supported?

Android 7.0 (API 24) and newer. The universal APK covers all architectures, and separate per-ABI builds are published for smaller downloads.

How do I back up my notes?

Back up and restore all notes to a JSON file in your Downloads folder, with optional automatic backups. Everything stays on your device — there is no cloud copy.

Where do I get updates?

Every release is published on the GitHub releases page. The app is also packaged for F-Droid-compatible repositories, so you can update through a client.

Can I build it myself?

Absolutely — that is the point of an open licence. Clone the repository, open it with JDK 21 and the Android SDK, and run ./gradlew assembleRelease.
